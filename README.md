# Browser Coach

**Live Demo:** https://kimnovix.github.io/browser-coach

A client-side JavaScript prediction engine that evaluates daily biometric inputs and logs performance history entirely within the browser.

## Features
* **Local Prediction Engine:** Calculates goal probability based on sleep, water, and steps using a weighted algorithm.
* **Session Memory:** Stores and renders a historical log of daily entries dynamically using the DOM.
* **Zero-Server Architecture:** Runs 100% client-side with no backend dependencies.

## Usage
1. Clone the repository: `git clone git@github.com:Kimnovix/browser-coach.git`
2. Open `index.html` in any web browser to interact with the engine.
